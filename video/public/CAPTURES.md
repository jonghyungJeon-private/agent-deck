# 선별 UI 에셋

- `icon.png`: 저장소 `Resources/AppIcon.icns`를 PNG로 변환.
- `spaces.png`, `collapsed.png`: 실제 spaces, 가상 세션 상태와 하위 에이전트.
- `split-before.png`, `split-drag.png`, `split-after.png`: 디버그 마우스 이벤트로 탭을 끄는 실제 앱 화면.
- `files.png`, `markdown.png`, `definition.png`: 실제 files와 편집기·미리보기·선언 이동.
- `settings.png`: 현재 브랜치의 실제 실행 옵션 설정 창(다음 판 기능).
- `JetBrainsMono-Regular.ttf`, `JetBrainsMono-OFL.txt`: 저장소 내 OFL 글꼴과 라이선스.

원본은 1200×760pt 창의 앱 내부 2배 스냅샷이다. 시스템 디스플레이나 다른 창을 읽지 않았다.
터미널은 내부 버퍼·글자 속성·글꼴을 별도 비트맵으로 그려 합성했다. 출력 내용은 전부 가상 데모다.
원시 캡처와 임시 실행 데이터는 gitignored `../.work/`에만 있다.
